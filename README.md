# How Its Built — browser extension

Open-source Chrome extension that shows how any website is built: frameworks, CMS, hosting, analytics and more. Detection runs locally in your browser.

Fingerprints come from [enthec/webappanalyzer](https://github.com/enthec/webappanalyzer) (GPL-3.0), so this repository is GPL-3.0 as well. Deeper analysis (versions, hosting, evidence) is available with [How Its Built Pro](https://howitsbuilt.fyi).

```sh
pnpm install
pnpm test
pnpm build
```
